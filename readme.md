# 原片实时库存系统 (Glass Inventory Management System)

## 项目概述

**系统名称**: 原片实时库存系统  
**版本**: 2.0.0  
**开发语言**: PHP 7.4+ + MySQL 5.7+ + HTML5/CSS3/JavaScript  
**适用场景**: 玻璃制造企业的原片库存管理  
**支持设备**: PC端管理 + 移动端操作 + API接口  

## 配套应用
- **移动端APK**: v1.0.22 [https://github.com/thriken/StockApp/releases/tag/v1.0.22](https://github.com/thriken/StockApp/releases/tag/v1.0.22)
-                v1.1.32 [https://github.com/thriken/StockApp/releases/tag/v1.1.32](https://github.com/thriken/StockApp/releases/tag/v1.1.32)
- **API文档**: 支持RESTful接口，便于第三方系统集成

## 系统特点

- **多基地管理**: 支持多个生产基地的独立库存管理和跨基地转移
- **实时库存**: 实时跟踪原片包的流转状态和库存数量
- **移动端支持**: 支持PDA/手机扫码操作，适合仓库现场使用
- **权限管理**: 多角色权限控制（管理员、库管、操作员、查看者）
- **数据追溯**: 完整的操作记录和流转历史追踪
- **跨基地转移**: 支持玻璃包在不同基地间的安全转移
- **盘点功能**: 完整的库存盘点流程，支持全盘、部分盘点和抽盘
- **API接口**: RESTful API支持，便于移动端和第三方系统集成
- **报表统计**: 每日领用总表和各类统计报表

## 核心功能模块

### 1. 基础数据管理
- **基地管理**: 多基地信息维护
- **库位架管理**: 库存区、加工区、报废区的库位架配置
- **原片类型管理**: 原片规格、品牌、生产商等基础信息
- **用户管理**: 用户账号、角色权限管理

### 2. 库存操作
- **采购入库**: 新采购原片包入库登记
- **领用出库**: 整包或部分领用到加工区
- **归还入库**: 加工后剩余原片归还库存
- **报废处理**: 不合格原片的报废处理
- **库存盘点**: 库存盘盈盘亏处理，支持全盘、部分盘点和抽盘
- **库位调整**: 同基地内的库位调整
- **跨基地转移**: 玻璃包在不同基地间的转移操作

### 3. 移动端功能
- **扫码操作**: 支持二维码/条码扫描
- **快速流转**: 移动端快速完成库存流转操作
- **实时查询**: 移动端实时查询包信息和库存状态
- **跨基地转移**: 移动端支持包的跨基地转移操作

### 4. API接口
- **RESTful API**: 标准REST接口，支持JSON数据格式
- **Token认证**: Bearer Token安全认证机制
- **操作接口**: 完整的库存操作API接口
- **查询接口**: 灵活的历史记录和库存查询接口
- **权限控制**: 基于角色的API访问控制

### 5. 报表统计
- **每日领用总表**: 按日期统计各基地领用情况
- **库存统计**: 实时库存数量和面积统计
- **流转记录**: 详细的操作历史记录，支持多条件筛选
- **盘点报告**: 完整的盘点结果和差异分析
- **数据导出**: 支持Excel格式数据导出

### 6. 系统管理
- **系统设置**: 基本参数配置
- **操作日志**: 用户操作记录追踪
- **数据备份**: 数据库备份和恢复
- **盘点任务**: 盘点任务的创建和管理

## 业务流程

### 1. 采购入库流程
采购到货 → 扫描包号 → 选择库位架 → 确认入库 → 更新库存
### 2. 领用出库流程
扫描包号 → 选择目标区域 → 输入领用数量 → 确认出库 → 更新状态
### 3. 归还入库流程
扫描包号 → 确认归还数量 → 选择库位架 → 确认归还 → 更新库存
### 4. 报废处理流程
扫描包号 → 选择报废原因 → 确认报废 → 更新状态为已报废
### 5. 跨基地转移流程
扫描包号 → 选择目标基地 → 系统自动分配临时库位 → 确认转移 → 更新位置
### 6. 库存盘点流程
创建盘点任务 → 扫描盘点 → 生成差异报告 → 确认盘点结果 → 更新库存


## 权限角色说明

- **admin（管理员）**: 系统全部功能权限，可跨基地操作
- **manager（库管）**: 库存管理、跨基地转移、报表查看权限
- **operator（操作员）**: 基本库存操作权限，仅限所属基地
- **viewer（查看者）**: 仅查看库存和报表权限，仅限所属基地

## 跨基地转移权限

- **管理员**: 可进行任意基地间的转移操作
- **库管**: 可进行跨基地转移操作
- **操作员/查看者**: 不能进行跨基地转移操作
- **安全机制**: 需要显式启用跨基地权限才能进行转移操作

## 安装部署

### 环境要求
- PHP 7.4+
- MySQL 5.7+ 或 8.0+
- Apache 2.4+ 或 Nginx 1.18+
- 支持PHP扩展：mysqli, json, session

### 部署步骤
1. 将项目文件上传到Web服务器目录
2. 创建MySQL数据库并导入glass_inventory.sql
3. 导入盘点功能表：导入inventory_check_tables.sql
4. 修改config/database.php中的数据库连接信息
5. 设置temp/和backups/目录的写入权限
6. 访问系统进行初始化配置

## API接口文档

### 认证方式
- **Bearer Token**: 所有API请求需要在Header中包含 `Authorization: Bearer {token}`
- **获取Token**: 通过登录接口获取访问令牌

### 主要接口

#### 库存操作
- `POST /api/scan.php` - 执行库存流转操作
- `GET /api/scan.php?action=get_package_info` - 获取包信息
- `GET /api/scan.php?action=get_target_info` - 获取目标库位信息
- `POST /api/scan.php?action=location_adjust` - 跨基地转移

#### 历史记录
- `GET /api/history.php` - 查询操作历史记录
- `GET /api/history.php?action=get_bases` - 获取基地列表

### 响应格式
```json
{
  "code": 200,
  "message": "操作成功",
  "data": {...}
}
```
