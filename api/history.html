操作记录查询 API

玻璃库存管理系统 - 历史操作记录接口文档

API 基本信息

GET
/api/history.php

功能描述

查询指定时间范围内的库存操作记录，支持多种筛选条件和分页查询。根据用户角色自动应用时间范围限制和基地权限过滤。

权限控制

管理员 admin

  • 可查询所有基地记录
  • 时间范围无限制
  • 可指定基地筛选

库管 manager

  • 只能查询本基地记录
  • 可查询本月1日至今记录
  • 支持跨基地操作查询

查看者 viewer

  • 只能查询本基地记录
  • 最多查询7天记录
  • 只读权限

操作员 operator

  • 只能查询本基地记录
  • 最多查询7天记录
  • 支持基本查询

时间限制规则

角色 默认查询范围 最大查询范围 说明
admin 最近7天 无限制 可查询任意时间范围
manager 最近7天 365天 最多查询一年记录
viewer/operator 最近7天 7天 只能查询7天内记录

认证方式

使用 Token 认证，需要在请求头中包含：

Authorization: Bearer {token}

请求参数

参数名 类型 必填 默认值 说明
start_date string 否 按角色设置 开始日期，格式：YYYY-MM-DD
end_date string 否 按角色设置 结束日期，格式：YYYY-MM-DD
package_code string 否 - 包号筛选，支持模糊搜索
operation_type string 否 - 操作类型：purchase_in, usage_out, partial_usage, return_in, scrap, check_in, check_out
base_id integer 否 - 基地ID筛选（仅管理员可用）
page integer 否 1 页码，从1开始
page_size integer 否 20 每页记录数，最大100

参数验证规则

  • 日期格式：必须为 YYYY-MM-DD 格式，如 2024-01-01
  • 日期范围：开始日期不能晚于结束日期
  • 查询天数：不能超过角色允许的最大天数
  • 基地权限：非管理员用户不能指定基地参数
  • 分页限制：page_size 最大为 100，超过时自动设为 100

错误响应

{
    "success": false,
    "message": "开始日期不能晚于结束日期",
    "error_code": "VALIDATION_ERROR"
}

常见错误码

HTTP状态码 错误类型 说明
400 VALIDATION_ERROR 参数验证失败
401 AUTHENTICATION_ERROR 认证失败或Token无效
403 PERMISSION_DENIED 权限不足
405 METHOD_NOT_ALLOWED 请求方法不被允许
500 SERVER_ERROR 服务器内部错误

使用示例

cURL 示例

# 基本查询
curl -X GET "https://your-domain.com/api/history.php" \
     -H "Authorization: Bearer your-token-here"

# 带筛选条件的查询
curl -X GET "https://your-domain.com/api/history.php?start_date=2024-01-01&end_date=2024-01-31&package_code=PKG001&operation_type=purchase_in&page=1&page_size=50" \
     -H "Authorization: Bearer your-token-here"

JavaScript 示例

// 基本查询
const response = await fetch('/api/history.php', {
    method: 'GET',
    headers: {
        'Authorization': 'Bearer your-token-here',
        'Content-Type': 'application/json'
    }
});

const result = await response.json();
if (result.success) {
    console.log('查询结果:', result.data.records);
} else {
    console.error('查询失败:', result.message);
}

// 带参数的查询
const params = new URLSearchParams({
    start_date: '2024-01-01',
    end_date: '2024-01-31',
    package_code: 'PKG001',
    operation_type: 'purchase_in',
    page: 1,
    page_size: 20
});

const responseWithParams = await fetch(`/api/history.php?${params}`, {
    method: 'GET',
    headers: {
        'Authorization': 'Bearer your-token-here'
    }
});

PHP 示例

// 使用 Guzzle HTTP Client
$client = new \GuzzleHttp\Client();

$response = $client->get('https://your-domain.com/api/history.php', [
    'headers' => [
        'Authorization' => 'Bearer your-token-here',
        'Accept' => 'application/json'
    ],
    'query' => [
        'start_date' => '2024-01-01',
        'end_date' => '2024-01-31',
        'package_code' => 'PKG001',
        'operation_type' => 'purchase_in',
        'page' => 1,
        'page_size' => 20
    ]
]);

$result = json_decode($response->getBody(), true);

if ($result['success']) {
    foreach ($result['data']['records'] as $record) {
        echo "包号: " . $record['package_info']['package_code'] . "\n";
        echo "操作类型: " . $record['operation_type_name'] . "\n";
        echo "操作日期: " . $record['operation_date'] . "\n\n";
    }
} else {
    echo "查询失败: " . $result['message'] . "\n";
}

实际使用场景

场景1：今日操作查询

查询今日所有的入库出库操作，用于日常库存监控。

GET /api/history.php

场景2：包号追踪

根据包号查询该包的所有历史操作记录。

GET /api/history.php?package_code=PKG202401001

场景3：月度统计

查询本月所有采购入库记录，用于月度报表。

GET /api/history.php?operation_type=purchase_in&start_date=2024-01-01&end_date=2024-01-31

场景4：跨基地查询

管理员查询指定基地的操作记录。

GET /api/history.php?base_id=2&page_size=100
